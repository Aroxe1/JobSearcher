# Application materials

Write in the language of the offer (or the user's language if unclear). Use real facts from the profile; never invent experience, degrees or skills. If something useful is missing (a project, a result), ask for it instead of making it up. When the offer asks for a skill the user lacks, don't claim it: either leave it out, or (if it's listed as required or a "plus") mention briefly and positively that they want to learn it, ideally with a first step taken. Leave unknown contact details as placeholders like `[Phone]`. Adapt to local norms: e.g. French CVs are usually 1 page, US résumés have no photo or age, German applications often include a fuller "Bewerbungsmappe".

## Tailoring a CV for an offer
1. Extract 5–8 keywords/requirements from the offer (skills, tools, missions).
2. Map each to evidence in the profile/CV. Flag gaps honestly.
3. Suggest concrete edits: headline/title matching the role, reorder sections, rewrite 2–4 bullets with action verb + task + result ("Built … that reduced … by …"), add missing keywords the user really has.
4. Keep it readable by applicant tracking systems: simple layout, standard headings, no text in images.

## Cover letter (short, ~250–350 words)
Structure ("you – me – us"):
1. **Hook (you):** why this company/role specifically — cite something real from the offer or company page.
2. **Me:** 2–3 proofs from the profile tied to the offer's needs (project, experience, skill + result).
3. **Us:** what they'd do together, availability (start date, rhythm for apprenticeships, duration for internships).
4. **Close:** propose an interview; polite sign-off appropriate to the language.

Avoid clichés ("dynamic and motivated", "I am writing to apply for…" as only opener). One page max.

## Application email (when sending CV + letter)
```
Subject: Application – <Role> (<contract type>, <start date>) – <First name Last name>

Hello <Name / Madam, Sir>,

<1–2 sentences: role applied for, where you saw it, one strong reason you fit.>
<1 sentence: availability (start, duration/rhythm).>
Please find my CV and cover letter attached. I'd be glad to discuss this in an interview.

Best regards,
<First name Last name>
<Phone> · <LinkedIn/portfolio>
```

## Unsolicited application (candidature spontanée)
Same as above but open with why *this* company (a product, value, recent news) and name the type of role/missions wanted. Target a named person (hiring manager, HR) when findable.

## Follow-up email (relance), ~7–10 days after applying
```
Subject: Follow-up – Application for <Role> (<date sent>)

Hello <Name>,

I applied on <date> for the <Role> position and remain very interested. <One line adding value: a recent project, availability update, or a link.>
Would you have any news on the next steps?

Best regards,
<First name Last name>
```
Second follow-up at most, ~2 weeks later; then move on.

## Interview prep
- Summarize the company (activity, size, recent news) from pages actually consulted.
- 5–8 likely questions (motivation, "tell me about yourself", strengths/weaknesses, a project, situational questions tied to the offer) with answer outlines based on the profile (STAR: Situation, Task, Action, Result).
- 3 smart questions to ask the recruiter.
- Practical: format (video/on-site), what to bring, apprenticeship/internship paperwork questions.

## Thank-you note after interview (same day or next)
Short: thanks, one point from the conversation, renewed interest.

**Reminder:** draft only. Sending anything requires the user's explicit approval.
